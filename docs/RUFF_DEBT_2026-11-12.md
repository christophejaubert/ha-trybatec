# Dette Ruff : première réduction / Ruff debt: first reduction

Baseline vérifiée / Verified baseline: GitHub Actions run 43186060507 (12 November 2026), before this branch.

## FR — Périmètre, preuve et règle progressive

Le contrôle Ruff intégral était informatif : près de 90 fichiers Python nécessitaient un formatage, et des diagnostics concernaient notamment les imports inutilisés F401 ainsi que les variables locales inutilisées F841. Les contrôles syntaxiques E9/F63/F7/F82 étaient déjà bloquants.

Cette première vague retire **15 diagnostics F401/F841 repérés** dans **11 fichiers** sans modifier les valeurs, les algorithmes, les assertions ni les appels réseau. Les suppressions concernent des imports inutilisés et une variable locale non lue dans un test synthétique.

La CI conserve le nom de statut obligatoire **ruff-essential** et impose désormais **zéro F401/F841 dans ces 11 fichiers**, afin que la dette correspondante ne réapparaisse pas. Les autres diagnostics Ruff et le formatage général restent consultatifs ; leur correction exigera des PR graduelles, distinctes des travaux fonctionnels en cours, notamment #82 et les PR d'interface.

**Limites :** supprimer des diagnostics n'est pas une preuve d'absence de bogue. La fusion exige toujours les dix contrôles GitHub, les tests Home Assistant isolés et la revue du diff. Le nettoyage global de 90 fichiers n'est pas accompli et ne doit pas être présenté comme tel.

## EN — Scope, evidence and incremental enforcement

The baseline GitHub Actions run 43186060507 reported extensive advisory formatting drift (around 90 Python files) and unused-import/local-variable diagnostics F401/F841. High-confidence syntax diagnostics were already blocking.

This first change removes **15 observed F401/F841 diagnostics** across **11 unrelated source/test files**, preserving functional expressions and test assertions; one unused local test variable was removed.

The existing required status **ruff-essential** now enforces **zero F401/F841** on these eleven cleaned modules, preventing reintroduction. Other pre-existing Ruff diagnostics and formatting drift remain advisory; clean additional areas in small non-overlapping PRs rather than mass-formatting functional branches (#82 and current panel PRs).

**Limit:** lower lint debt does not imply functional correctness. Exact-SHA CI, isolated Home Assistant tests, full diff review and separate live acceptance remain necessary. Comprehensive repository-wide Ruff cleanup is not yet complete.
